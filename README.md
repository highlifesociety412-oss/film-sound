# film-sound

Sound Bot repo — Supervising Sound Editor / Composer for Maxi Universe / Reev Cannon.

## Layout
- `maps/` — spotting documents
- `scores/` — compositions and stems
- `vo/` — voiceover tracks
- `sfx/` — effects by category (impacts, ambience, creatures, machines)
- `foley/` — synced prop and movement sounds
- `mixes/` — temp and final masters
- `library/` — growing SFX database with tags
- `logs/` — daily notes and deviation reports
- `references/` — Showrunner-approved audio style references

Shared: `/workspace/film/sound/maps/`, `/workspace/film/sound/mixes/`, `/workspace/film/master/`
